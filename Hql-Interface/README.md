# Hql-Interface

Web front end for the HQL query engine — a SIEM-style query workspace built with
Vite + React 18 + TypeScript + Tailwind and a grammar-aware CodeMirror 6 editor.

For design context and non-obvious constraints, read [`claude-notes.md`](./claude-notes.md).

## Prerequisites

- **Node.js 22+** (the project relies on ES2022 semantics and Node 22's
  TypeScript type-stripping for headless smoke tests)
- **npm** (ships with Node)
- The HQL backend from this repo, for anything beyond building the static bundle

No Java runtime is required — the ANTLR TypeScript target is generated by the
pure-TS `antlr-ng` package.

## Install

```
cd Hql-Interface
npm install
```

## Build

```
npm run build
```

This runs `tsc` for type-checking and then `vite build`, emitting the static
bundle to `dist/`. The backend serves `dist/index.html` at `/` and mounts
`/assets` — nothing else. Every asset must go through the bundler, never an
absolute URL.

The generated parser (`src/hql/generated/HqlLexer.ts`,
`src/hql/generated/HqlParser.ts`) is committed. Regenerate it only when the
grammar files change:

```
npm run gen:parser
```

That reads `../Hql/Parser/grammar/Hql.g4` (with `HqlTokens.g4` via `--lib`) and
prepends `// @ts-nocheck` to each output. Never hand-edit the generated files —
fix the script instead.

## Development loop

Start the backend in one shell:

```
uv run python -m Hql -eng -d ./examples/interface
```

Start the Vite dev server in another (from `Hql-Interface/`):

```
npm run dev
```

The dev server listens on **5173** and proxies `/api` to the backend on
**8080**. Do not run the dev server on 8080 — that collides with the backend
and would proxy to itself.

## Lint

```
npm run lint
```

ESLint is configured with `--max-warnings 0`; generated parser files under
`src/hql/generated/` are excluded.

## Preview a production build

```
npm run build
npm run preview
```

`preview` serves the built `dist/` locally for a smoke check without the real
backend. To exercise the full app, run the backend and open `:8080` instead —
that is what ships to users.

## Layout

- `src/components/` — React components (editor, results, panels)
- `src/hql/` — grammar-aware editor pieces (highlight, lint, complete, theme)
  and generated parser under `generated/`
- `src/state/` — context + reducer store
- `src/hooks/`, `src/lib/`, `src/types/` — supporting utilities
- `lain.gif` — running-query indicator, imported through the bundler
- `dist/` — build output served by the backend
